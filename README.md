# Chhattisgarh Formal Survey Report — Interactive Presentation

The primary presentation in this folder is an interactive HTML deck for the Rural Immersion and Innovation project. The original source PowerPoint is retained as a source record; it is not the updated interactive deliverable.

## Main files

| File | Purpose |
| --- | --- |
| `index.html` | 17-slide interactive presentation with keyboard and touch navigation, slide overview, print layout, and click-to-explore context cards. |
| `CONTENT_AUDIT.md` | Slide-by-slide review, editorial decisions, evidence gaps, and research sources. |
| `data/source.pptx` | Original 13-slide source deck, preserved unchanged. |
| `data/content-manifest.json` | Inventory of the source presentation’s text blocks. Slide 13 was editorially replaced in the HTML version to remove draft submission prompts and state the evidence boundary. |
| `assets/images/` | Locally stored photographs and illustrations with provenance in `IMAGE_ATTRIBUTIONS.md`. |

## Presentation structure

Slides 1–12 cover the original survey topics. Slide 13 now clarifies the evidence boundary and gives questions for the rural immersion. Slide 14 presents corrected dated state indicators; slide 15 compares rural and urban multidimensional-poverty estimates across the 2015–16 and 2019–21 survey periods; slide 16 presents proposed next steps; slide 17 links directly to source publications and image attributions.

The project folder contains no household interviews, village service measurements, or team field photographs. The presentation therefore makes no claim that these are field findings. Statewide indicators are dated and should not be read as measures of every village or as current 2026 estimates.

## Run the presentation

Open `index.html` in a modern browser. It uses bundled fonts and local assets. Navigation: arrow keys or PageUp/PageDown to move, Home/End to jump, O for overview, F for fullscreen, Space or P to play/pause, and Escape to close the overview or fullscreen.

## Source and figure notes

- Forest cover is from the Forest Survey of India, *India State of Forest Report 2023*.
- Rural and urban MPI figures are from NITI Aayog’s *National Multidimensional Poverty Index: A Progress Review 2023* and refer to NFHS-4 / NFHS-5 survey periods.
- Mineral shares are shares of reported national resources in the Indian Bureau of Mines’ *Indian Minerals Yearbook 2023*, not shares of annual production.
- Demographic figures shown on the statistics slide are from Census 2011.
- The agriculture card uses ICAR’s crop profile and is labelled as a profile figure, not a current annual estimate.

For the slide-level review and direct source links, see `CONTENT_AUDIT.md` and the deck’s final references slide. The existing PDF, PPTX, and screenshot exports have not been regenerated and may not match this HTML deck.
